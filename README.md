## Project Description
This project is based on studying an open-source software called Git. It includes five shell scripts that demonstrate basic Linux commands and scripting concepts.

## Scripts

### Script 1: System Identity Report
This script displays system details such as OS type, kernel version, current user, uptime, and date.it is saved as script1.sh

 ## Script 2: Package Inspector
This script checks whether Git is installed on the system and shows its version.it is saved as script2.sh

### Script 3: Disk and Permission Auditor
This script checks important directories and displays their size and permissions.it is saved as script3.sh

### Script 4: Log File Analyzer
This script reads a log file and counts how many times a keyword appears.it is saved as script4.sh

### Script 5: Manifesto Generator
This script takes user input and generates a personalized open-source manifesto saved in a text file.it is saved as script5.sh
